# 过了么AI — 实时面试 / 会议辅助工具

> **Windows 桌面应用** · Electron + React · OpenAI Realtime 一体音频直通

面向各类岗位的实时面试辅助工具，同时支持**项目会议答疑模式**。  
以悬浮窗形式在桌面显示，监听对方的提问后自动给出精炼回答提词，帮你更从容地应对每一个问题。

支持中英文面试：在 Settings 顶部一键切换答案语言，中英文组会/面试均可使用。

**iOS 伴机版**（SwiftUI）源码在 [`ios/`](./ios/README.md)：面试在电脑上进行，iPhone 用麦克风听外放并在本机显示提词。需 Mac + Xcode 编译，上架说明见 [`ios/docs/AppStore-Review.md`](./ios/docs/AppStore-Review.md)。

## 核心功能

| 功能 | 说明 |
|---|---|
| **实时提词卡** | 监听问题后快速给出一句可朗读回答与关键词 |
| **可读答案模式** | 一句回答无缝展开为 3-4 句自然表达 |
| **中英文答案切换** | Settings 顶部一键切换，中文面试/组会同样适用 |
| **Realtime 一体模式** | 音频直接送入模型，省去 Whisper 中转，延迟更低 |
| **JD / 简历 / 笔记上下文融合** | 基于岗位要求和你的经历生成更贴合的回答思路 |
| **历史记忆与追问应对** | 结合近期问答历史，对追问进行自然衔接回答 |
| **会议 / 项目介绍模式** | 上传项目文档，根据文档内容实时答疑（支持 PDF / TXT / DOCX） |
| **会议助手（v3.0.0）** | 以你的个人画像、本周进展、历史会议记忆为依据，在会上被点到时弹出第一人称英文答题卡 |
| **实时翻译总结** | 监听对方讲话，随时一键把当前段落转写并总结成 1-2 句精炼中文，流式输出、按时间轴回顾 |
| **下一题自动切换** | 识别到新一轮提问时自动收起旧卡、继续监听 |
| **一键导出复盘** | 将本次面试的问答记录导出为 PDF，附带 AI 生成的中文总结 |
| **多 AI 服务商** | 支持 OpenAI / Google Gemini / DeepSeek / 千问 / Ollama 本地 |
| **系统音频捕获** | WASAPI loopback 直接录制扬声器输出，不录麦克风 |

## 开发环境运行

### 环境要求

- Node.js >= 18
- Windows 10 x64 及以上（原生音频模块仅支持 Windows）

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

同时启动 Vite 前端（端口 5173）和 Electron 主进程，支持热重载。

### 打包 Windows 安装包

```bash
npm run dist:win
```

产物输出到 `release/` 目录。

## 首次使用配置

### 1. 配置 API Key

应用使用 OpenAI API（或其他服务商），Key 通过系统 keychain 安全存储，不会写入任何文件。

1. 打开 [platform.openai.com/api-keys](https://platform.openai.com/api-keys) 创建 Key
2. 确保账户已绑卡并有可用额度（[Billing 页面](https://platform.openai.com/account/billing)）
3. 在应用 **Settings** 中粘贴 Key，点击「测试连接」确认通过

> ChatGPT Plus 订阅**不等于** API 额度已开通，需单独充值。

### 2. 推荐设置

- **答案语言**：Settings 顶部切换 English / 中文，中英文面试均可
- **服务商**：OpenAI，模型默认 `gpt-5-mini`
- **模式**：默认开启 Realtime 一体（音频直通，延迟最低）
- **回答风格**：极简提醒（Concise）日常使用；卡壳时切换可读答案
- **音频来源**：System Audio（监听对方声音）；自测时换 Microphone

### 3. 使用流程

1. 上传资料（JD / 简历 / 笔记），点击「根据资料自动优化」
2. 点击「开始监听」
3. 面试中先读一句回答，再按关键词展开；卡壳时切可读答案模式
4. 面试结束后点「一键导出」生成 PDF 复盘报告

## 会议 / 项目介绍模式

在 **Settings** 中开启「会议模式」，上传项目文档（支持 PDF / TXT / DOCX），模型会深度内化文档内容，根据与会者的提问实时给出有据可查的回答——适合技术评审、项目汇报、演示答疑等场景。

## 会议助手（v3.0.0 新增）

面向自己开会的场景（周组会进展汇报、新项目探讨、合作方技术会谈、作为面试官面试候选人），在**组会模式**和**翻译总结模式**下都可用。

1. 顶栏 🎯「会议准备」：
   - **场景 & 弹卡**：选择会议场景（周组会 / 新项目探讨 / 合作方会谈 / 我是面试官）和弹卡方式（点到我才弹 / 所有问题都弹 / 只按热键），填写点名关键词（你的名字及转写常见误拼）。
   - **我的画像**：粘贴个人画像（角色、产品、架构、同事分工、沟通风格），或从资料库文档生成草稿。答题卡会以你的身份、第一人称作答。
   - **本周进展**：用中文写几条，一键生成英文汇报稿、可能被追问的问题与参考答案、需要团队拍板的问题。
   - **会议记忆**：每场会议结束后自动记下被问到什么、怎么答的、答应了什么，下次会议作为上下文。
2. 会中：
   - 对方发言实时转写，被点到时弹出答题卡：中文问题、开口一句、3 条要点、可直接说的回答、依据与风险提醒（文档里没有的数字不会编）。
   - 合作方会谈场景下自动开启保密边界，不主动透露成本、IP、未公开计划等。
   - 翻译总结模式下，卡片浮在总结上方，按 Space 收起后继续看总结。

| 快捷键（全局） | 操作 |
|---|---|
| `Ctrl + Shift + 1` | 根据最近的发言生成答题卡（回答刚才的问题） |
| `Ctrl + Shift + 2` | 中文想法 → 可以直接说出口的英文 |

## 实时翻译总结（v1.8.0 新增）

面向"听不懂对方在说什么，需要快速理解大意"的场景，例如：外语会议 / 电话、英文演讲直播、跨语言一对一沟通等。与面试问答模式互斥，在 **Settings → 翻译总结模式** 中开启后，主界面会切换为翻译总结面板。

**使用方式**：

1. 点击「开始监听」，应用开始持续捕获系统音频（对方声音）或麦克风；
2. 按语音停顿（VAD 静音检测）自动把讲话切成一段一段，缓存在本地，不会自动发送；
3. 任意时刻点击「翻译总结」，应用会把缓存中的所有语音段拼合，送入 Whisper 转写成文字，再交给 GPT 模型总结成 **1-2 句自然、精炼的中文**（自动过滤 ASR 重复词、口头禅，保留专有名词），以打字机效果流式展示；
4. 每次总结都会带上时间戳追加到列表顶部，可随时向下滚动回顾之前的翻译总结；
5. 监听可以一直保持开启，说话内容会持续进入下一轮缓冲区，等你下次点击「翻译总结」时再处理——不需要频繁开关监听。

技术上复用了与面试模式相同的音频捕获与 VAD 分段管线，仅将分段结果导向独立缓冲区，点击总结时才触发一次 Whisper 转写 + Chat Completions 流式总结，不占用面试问答模式的实时会话。

## 技术栈

- **前端**：React 18 + TypeScript + Vite
- **桌面壳**：Electron 31
- **音频**：WASAPI loopback（`wasapi-loopback` 原生模块）/ PortAudio naudiodon
- **AI**：OpenAI Realtime API / Chat Completions / Whisper
- **存储**：Electron userData JSON + keytar（Key 安全存储）

---

## 本地存储说明

- **API Key**：通过 `keytar` 存入系统 keychain，不写入任何文件
- **设置 / 资料摘要 / 历史提问**：存放于 `app.getPath('userData')` 下的 JSON 文件，重启后保留
